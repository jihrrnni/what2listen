# 今日、何聴く？

好きなアルバムを登録しておくと、その中から「今日聴く一枚」をランダムで選んでくれる小さなWebサイトです。

## Features

- アルバムを手動で登録
- ジャケット画像URLを登録可能
- Spotify / Apple Musicなどの再生ページURLを登録可能
- ブラウザのLocalStorageに保存
- 「今日の一枚」をランダム選択
- 選ぶたびに一言メッセージもランダム表示
- 外部API・サーバー不要

## 使い方

1. `index.html` をブラウザで開く
2. アーティスト名とアルバム名を入力
3. ジャケット画像URLと聴くためのURLは必要なら入力
4. 「今日の一枚を決める」を押す

## GitHub Pagesで公開する場合

このリポジトリをGitHubにアップロードして、Settings → Pages → Deploy from a branch → `main` / `/ (root)` を選択してください。
